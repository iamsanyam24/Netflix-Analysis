# Netflix Data Analysis

## Overview
This project analyzes Netflix movies and TV shows using Python.
The goal is to understand trends in content type, release years, genres,
and country-wise distribution.

## Dataset
The dataset contains information about Netflix titles such as:
- Title
- Type (Movie / TV Show)
- Country
- Release year
- Genre

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Analysis Performed
- Movies vs TV Shows comparison
- Content growth over the years
- Country-wise content distribution
- Genre-based analysis

## Key Insights
- Netflix has more movies than TV shows.
- Content additions increased rapidly after 2016.
- The United States contributes the most content.
